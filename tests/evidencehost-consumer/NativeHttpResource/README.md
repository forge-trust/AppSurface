# Native HTTP resource for the restricted Aspire child

This .NET 10 ASP.NET Core executable is the single real resource in the [provisional Aspire child mechanism](../AspireChild/README.md). It has no Evidence assemblies, Docker dependency, TCP application endpoint, registration callback or verifier. Kestrel listens only on the root-selected private Unix-domain socket.

The closed entry arguments are `--socket <absolute-path> --case normal|readiness-failure|cancel|stuck-descendant`. `/health` returns the exact text `native-http-ready` only when `File.OpenRead` and `Assembly.LoadFile` of `protected-tool.dll` both fail through access denial/masking, `FileMode.CreateNew` of `native-resource-output-probe` is denied, the declared input is read with its exact expected contents, and the readiness-failure control is absent. The tool-read check requires access denial; a masked file during the independent assembly-load attempt is accepted only alongside that denied read and the controller's existing managed-file prerequisite. Protected paths and immutable `proof-input/declared.txt` come from the controller through explicit environment bindings. Missing bindings fail startup. Accessible protected files/output, mismatched input, and readiness failure return HTTP 503. No secret contents are printed. This synthetic fixed response proves provisional fixture mechanism denial only, not worker verification authority, application correctness or trust.

`stuck-descendant` starts the same compiled fixture with `--descendant`; that finite test topology includes a descendant which ignores SIGTERM and waits indefinitely until the root-selected cgroup is killed. It cannot move cgroups or change identity. This control demonstrates why application disposal alone does not establish owned exit. Root always confirms the entire unit is empty and joins its output pumps before cleanup.

The AppHost project builds/copies this output automatically. Platform execution is deferred to native parent CI; portable compilation does not establish Linux acceptance.
