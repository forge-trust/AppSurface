- [Coverage fan-in](../../guides/coverage-fan-in.md#opt-in-schema-v3-report-based-patch-applicability) adds an opt-in v3 contract that distinguishes measured patch coverage, no reported changed measurements (N/A), and unverified evidence. N/A trusts the accepted collector's reports; it does not prove the source has no executable code. The existing v2 default, coverage thresholds and required capture checks remain. Repository N/A enablement awaits complete fresh native, Evidence and resource qualification.
