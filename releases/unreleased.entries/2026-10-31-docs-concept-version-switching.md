- **Guide continuity across documentation versions:** [AppSurface Docs](../../Web/ForgeTrust.AppSurface.Docs/README.md#concept-switch-artifacts)
  can follow an authored concept when its guide moves or changes title, with a
  clear notice and the selected release and language preserved. Missing,
  ambiguous, or unavailable counterparts offer verified recovery links and a
  return to the original guide.
- Hosted archives and generated static publications share the same identity
  rules and plain-link fallback. The [version-switching guide](../../guides/version-switching.md)
  documents stable concept IDs, pinned legacy bridges, artifact limits, and a
  two-release walkthrough. Original release archives remain immutable.
