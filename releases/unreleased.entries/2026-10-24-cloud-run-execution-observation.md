- Applications using [Cloud Run deployment bundles](../../Deployment/ForgeTrust.AppSurface.Deployment.GcpCloudRun/README.md#exact-cloud-run-execution-observation) can observe one exact Job execution through `IGcpCloudRunExecutionObserver` or [`appsurface deployment gcp-cloud-run observe-execution`](../../Cli/ForgeTrust.AppSurface.Cli/README.md#appsurface-deployment-gcp-cloud-run-observe-execution). The observer compares captured execution configuration and current terminal evidence against the bundle, with bounded reads, cancellation, safe diagnostics, and distinct failure, unknown, and running outcomes. Optional `projectNumber` binds numeric execution namespaces to the declared project; v1 single-container Gen2 SQL configuration uses the documented implicit socket projection. Try the [two offline consumers](../../examples/cloud-run-execution-consumers/README.md). Submission, recovery, and application acceptance remain caller-owned; the checked-in offline evidence makes no live provider-certification claim.
