- **Validate a supplied CLI package without issuing an EvidenceHost claim.** The repository's [direct package recipe](../../tools/ForgeTrust.AppSurface.Evidence.Validation/README.md#run-the-direct-package-journeys) now writes `native-validation-receipt.json` after checking every selected journey, assertion, artifact and cleanup result. Consumers of the direct recipe should read that receipt instead of expecting an EvidenceHost manifest. [Policy-backed repository operations](../../tools/ForgeTrust.AppSurface.Evidence.Validation/README.md#local-development) retain their existing manifest verification and coverage gates. The [ordinary AppHost readiness example](../../examples/aspire-apphost/README.md#deterministic-profile-test) uses the typed Aspire testing builder and makes no EvidenceHost claim.
