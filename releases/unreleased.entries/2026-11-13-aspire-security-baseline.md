### Aspire security baseline update

The coordinated Aspire minimum for the AppHost SDK, `Aspire.Hosting`, and `Aspire.Hosting.Testing` is now **13.6.5**, which includes the fix for [GHSA-f7vh-h5g3-7jrh](https://github.com/dotnet/announcements/issues/503). The [Aspire integration](../../Aspire/ForgeTrust.AppSurface.Aspire/README.md#dependency-security) does not have a NuGet dependency on the Aspire CLI. Strict NuGet vulnerability auditing remains enabled. Aspire 13.6.5 package metadata requires Microsoft.Extensions.Hosting and Microsoft.Extensions.DependencyInjection **10.0.14** and MessagePack **2.5.307**. Existing 13.4.4 and 13.4.6 consumer proofs are historical and do not establish compatibility for 13.6.5; later versions are permitted by the open-ended package minimum but remain unverified and require compatibility proof.

The [central dependency graph](../../Directory.Packages.props) also advances Aspire.Hosting.Keycloak to **13.6.5-preview.1.26559.7**, Aspire.Hosting.PostgreSQL to **13.6.5**, the pinned Microsoft.Extensions packages to **10.0.14**, OpenTelemetry packages to **1.17.0**, and YamlDotNet to **18.1.0**. The [Cloud Tasks transport](../../Durable/ForgeTrust.AppSurface.Durable.CloudTasks/README.md) pin for Grpc.Net.Client advances to **2.83.0** to keep shared graphs aligned. These central pins also raise dependency floors in non-Aspire packages that consume them; preserve these minimums in consumer overrides.
