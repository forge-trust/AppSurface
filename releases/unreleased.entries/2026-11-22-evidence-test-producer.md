- `appsurface evidence` has a preview built-in [`test` producer](https://github.com/forge-trust/AppSurface/blob/main/Evidence/ForgeTrust.AppSurface.Evidence.Cli/README.md#test-producer-preview) for changed paths that have no production code to cover. It runs the test projects a policy declares and closes its assertion only when every selected test ran once and passed; it makes no coverage claim. The kind, its assertion id and its receipt format may still change.
- `appsurface evidence verify` now checks every manifest-listed artifact on disk and accepts `--artifact-root`. `appsurface evidence run` deletes the earlier manifest, summary and `test` producer artifact directories before it starts. See [Verifying evidence](https://github.com/forge-trust/AppSurface/blob/main/Evidence/ForgeTrust.AppSurface.Evidence.Cli/README.md#verifying-evidence). Upgrade every CLI that runs or verifies evidence before adding a `test` block to a shared policy.
