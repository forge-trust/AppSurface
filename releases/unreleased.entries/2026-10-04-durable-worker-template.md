### Application-owned Durable worker starter

The [Durable worker quickstart](../../start-here/durable-worker.md) introduces the `ForgeTrust.AppSurface.Durable.Templates` package and `appsurface-durable-worker` template for hosts that activate Work through an authenticated ASP.NET Core route. It generates a typed Work definition, passive PostgreSQL composition, distinct health endpoints, telemetry and standalone tests. The disposable first-Work proof exercises authorization, terminal completion, readiness and exported activity against restricted PostgreSQL roles using the [canonical packaged role recipe](../../Durable/ForgeTrust.AppSurface.Durable.PostgreSql/README.md).

The template uses the existing coordinated package publication path, with exact archive/feed installation, generated-content validation, ordinary startup on three native OS runners and separate five-sample timing evidence required before publication. Those candidate checks do not certify a downstream deployment. Generated code belongs to the application; subsequent template installation affects future projects. The [initial shape guide](../durable-worker-template-shape-v1.md) explains compatibility and manual updates.
