- AppSurface's [repository EvidenceHost acceptance](../../tools/ForgeTrust.AppSurface.Evidence.Validation/README.md#local-development) now selects solution coverage, package validation and native acceptance from the same checked-in policy locally and in CI. C# Git collection includes local branch/working-tree changes and event-pinned CI changes. Explicit profile combination unions requirements for mixed changes; unknown inputs retain every producer. Local execution captures dirty patch content, builds native candidates only when selected and rejects source drift. CI emits verified native, coverage and package lane manifests, retaining full-solution 95/85 aggregate and applicable 95/85 patch gates with existing tolerance and native fan-in. Package checks retain catalog, generated-documentation and packed-consumer proofs while avoiding duplicate restore/build steps. Collection, fan-in and verification use C#.
- The [Durable worker template](../../Durable/ForgeTrust.AppSurface.Durable.Templates/content/durable-worker/README.md) creates test hosts without configuration file reload watchers, preventing authored tests from stalling during builder construction on restricted hosts. Application reload defaults and acceptance timeouts remain unchanged.
