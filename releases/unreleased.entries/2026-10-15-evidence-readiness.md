### Bounded HTTP readiness for typed Aspire tests and EvidenceHost — issue #867

The approved `ForgeTrust.AppSurface.Evidence.Readiness` package provides a BCL-only, deadline-bounded HTTP status probe for ordinary tests. Its typed Aspire fixture composes the existing profile builder, native resource health, explicit endpoint selection, and the HTTP condition under one cooperative startup budget. The Evidence.Aspire adapter adds that condition to an explicitly registered EvidenceHost resource while retaining the existing application lease as its sole owner.

Use the [neutral readiness reference](../../Evidence/ForgeTrust.AppSurface.Evidence.Readiness/README.md), [typed fixture guide](../../Aspire/ForgeTrust.AppSurface.Aspire.Testing/README.md#http-readiness-fixture), [Evidence.Aspire adapter guide](../../Evidence/ForgeTrust.AppSurface.Evidence.Aspire/README.md#http-readiness-adapter), and [EvidenceHost guide](../../start-here/evidencehost.md#aspire-http-readiness) for defaults, ownership, cancellation, safe diagnostics, and alternatives. The [standalone consumer](https://github.com/forge-trust/AppSurface/tree/main/tests/evidence-readiness-consumer) and [typed consumer](https://github.com/forge-trust/AppSurface/tree/main/tests/evidence-readiness-typed-consumer) are the canonical executable quickstarts; use the [verification script](https://github.com/forge-trust/AppSurface/blob/main/scripts/verify-evidence-readiness-consumers.sh) for their package proofs.

Both version-bound Skoolit gate equivalences preserve a three-minute startup budget, 30 requests, three-second request timeout, 250 ms retry, `UseProxy = false`, and two-second `ConnectTimeout`. Those settings are consumer choices, not SDK defaults. Equivalence proof is not actual Skoolit adoption, and no latency or reliability improvement is claimed without measurements. Aspire 13.4.4 is the pinned verification baseline; later consumer-selected versions require their own verification. Runtime, live-resource, and packed-consumer results belong to the corresponding proof records, not to this documentation entry.
