### C# API semantic rendering

- AppSurface Docs now renders built-in C# namespace API pages from an internal semantic tree and constrained Razor partials, preserving the single shell heading, stable API anchors, source links, disclosures, and encoded XML documentation values. Consumer host setup, routing, and custom `IDocHarvester` migration are not required. Maintainers can follow the [C# API rendering architecture and testing guide](../../Web/ForgeTrust.AppSurface.Docs/README.md#c-api-rendering-architecture-and-testing) for the compatibility boundary, diagnostics, and focused verification commands.
