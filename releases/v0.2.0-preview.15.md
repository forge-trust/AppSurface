# Release 0.2.0-preview.15

AppSurface 0.2.0-preview.15 is a coordinated prerelease after `0.2.0-preview.14`.

This preview adds the opt-in [Google Cloud Tasks activation adapter](../Durable/ForgeTrust.AppSurface.Durable.GoogleCloudTasks/README.md#install-and-configure), a [Durable worker starter](../start-here/durable-worker.md), and [guide continuity across documentation versions](../guides/version-switching.md). Check the [migration notes](#migration-watch) for changes to repository-relative AppHost assets and native parser packaging.

## Migration watch


### AppHost repository-relative asset paths — [issue #865](https://github.com/forge-trust/AppSurface/issues/865)

`AspireStartupContext` now anchors default repository discovery at `builder.AppHostDirectory` and uses the nearest `.git` directory or file, including linked-worktree markers. Relative explicit `applicationRoot` values that were previously accepted now fail validation; supply a nonblank fully qualified path when constructing a context directly. When no root can be discovered, repository-path requests now fail with a helpful error instead of returning a silent relative path, while path-free profile and factory use remains available. Follow the [canonical repository-relative assets guide](../Aspire/ForgeTrust.AppSurface.Aspire/README.md#repository-relative-assets) for asset checks and recovery. This behavior change is covered by the [pre-1.0 upgrade policy](upgrade-policy.md).

- The [AppSurface Docs NuGet package](../Web/ForgeTrust.AppSurface.Docs/README.md#tree-sitter-native-assets-in-build-and-publish-output) now keeps only the SDK host's Tree-sitter natives in ordinary build and publish output when there is an exact eligible RID match. Use an explicit publish RID for a known destination or set `AppSurfaceDocsKeepAllTreeSitterRuntimes=true` for an artifact that needs all bundled platforms.
