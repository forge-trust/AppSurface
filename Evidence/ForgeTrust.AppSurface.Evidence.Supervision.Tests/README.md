# Supervision procedure tests

[`SupervisionApplicationCleanupTests`](SupervisionApplicationCleanupTests.cs) verifies the ordered application cleanup callback procedure: begin-stop placement, monitor cancellation and lifetime join, monitor cancellation filtering, body failure handling, and final active-work completion. These tests exercise callbacks only. They do not construct a native application owner or qualify owner identity, terminal state, cgroup emptiness, pump joins, native resource disposal, or settlement publication. Those facts remain checks in [`LinuxApplicationProcess`](../ForgeTrust.AppSurface.Evidence.Supervision/LinuxApplicationProcess.cs) and require the native application qualification path.

The procedure is [`SupervisionApplicationCleanup.RunAsync`](../ForgeTrust.AppSurface.Evidence.Supervision/SupervisionApplicationCleanup.cs). Use it only to test or share the fixed ordering around callbacks borrowed from one actual owner. Keep admission, deadlines, physical cleanup evidence, and policy decisions in that owner. See the supervision package's [`worker cleanup reference`](../ForgeTrust.AppSurface.Evidence.Supervision/worker-cleanup.md) and [`producer cleanup reference`](../ForgeTrust.AppSurface.Evidence.Supervision/producer-cleanup.md) for related callback-order procedures.


[`LinuxNamedEntryNativeTests`](LinuxNamedEntryNativeTests.cs) runs the shared [actual-name comparison](../ForgeTrust.AppSurface.Evidence.Supervision/LinuxNamedEntry.cs) against owned temporary Linux filesystem objects. Four cases cover directory child churn versus identity/policy changes, exact file mutation/replacement, unchanged native missing/symlink/escape errors, and borrowed parent lifetime with each original resolution mode. They use actual openat2/statx and skip outside Linux x64. They establish filesystem behavior only, never protected workspace ownership, account creation, worker admission or consumer acceptance.
