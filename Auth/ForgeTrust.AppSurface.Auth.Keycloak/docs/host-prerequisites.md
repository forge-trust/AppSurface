# Host prerequisites

The supported host is Unix-like and must preserve executable modes, provide Docker 29-compatible OCI layout build contexts with the containerd snapshotter, and create absent snapshot/context destinations. The host supplies the complete explicit recipe, policy, capture bindings, and actual immutable image identity. The repository-held schema is not currently published; future publication depends on the separate pure publish decision and coordinated dependency authorization. The package uses managed .NET code and two runtime dependencies: `BouncyCastle.Cryptography` for signed Release verification and `ZstdSharp.Port` for compressed Debian payload handling. Python is used only by CI harnesses.

The host should run capture sequentially when disk is bounded. Keep original source archives and captured receipts; remove only package-owned staging, selected copies, and temporary contexts after their hashes and manifests have been recorded. Do not delete captured originals as cleanup.

Docker invocation must use `KeycloakBuildContext.CreateDockerBuildArguments` and `ProcessStartInfo.ArgumentList`. The fixed arguments include `--provenance=false` so the local Docker identity is the selected platform manifest. An attestation-bearing index is rejected as unsupported by the local resolver; resolve an explicit platform manifest before inspection. Do not interpolate the argument list into a shell, add a registry push, or enable network access to the offline build. The image tag is a local host choice; `ResolveLocalImageAsync` must resolve that tag through Docker 29 containerd metadata and full export hashing before inspection. Labels are advisory and cannot replace manifest/config/diff-ID evidence. Resource limits bound work and metadata; they do not promise a fixed process RSS ceiling.

Keep exclusive ownership of the context from `Verify` through completion of the host builder. The context is a mutable host-owned directory; verification is a point-in-time integrity check. Inspection verifies the final immutable image against the documented application and runtime profile checks, and does not attest a hostile host or every unrelated host-composed filesystem path.
