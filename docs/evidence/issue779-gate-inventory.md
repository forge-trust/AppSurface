## Current claim kinds to migrate

The public [claim and eligibility enums](../../Evidence/ForgeTrust.AppSurface.Evidence.Contracts/EvidenceContracts.cs#L38-L90) are `None`, `TargetedComplete`, `ReleaseComplete`, `NoEvidenceRequired`, and `ObservationOnly`; eligibility is `None`, `PullRequestGate`, `ReleaseGate`, or `Informational`.

| Claim | Current behavior | Required #779 treatment |
| --- | --- | --- |
| `TargetedComplete` | `EvidenceManifestBuilder.Build` can return `PullRequestGate` from passed producer results while `EnvelopeStatus` is `NotRequired`. | `Trusted` only: accepted registered assertion, valid bindings, obligations, and cleanup. |
| `ReleaseComplete` | Builder requires the enum value `ValidatedNotAttested`; Aspire calls a registered verifier for release profiles, but the current result is only a Boolean `Accepted`. | `Trusted` only, with a registered versioned assertion; retain release opt-in and `ValidatedNotAttested`, never `Attested`. |
| `NoEvidenceRequired` | An explicit empty policy profile currently becomes pull-request eligible without admission. | `Trusted` when gate-eligible. It is not the Observation starter and cannot be inferred from skipped work. |
| `ObservationOnly` | A Boolean changes the final claim after the selected work has run; eligibility is informational. | Explicit `Observation` admission for a declared dependency-free profile with no resources, privileged producer classes, or sensitive projections. It never gates. |
| `None` | Invalid or incomplete execution has no gate eligibility. | Preserve; timeout, cancellation, cleanup failure, or invalid input cannot be promoted. |

The claim mapping is implemented in [`EvidenceManifestBuilder.Build`](../../Evidence/ForgeTrust.AppSurface.Evidence.Contracts/EvidenceContracts.cs#L1055-L1169). The design requires all three gate-capable kinds above to consume a host-issued admission result, not a caller-supplied envelope-status enum, and keeps `Verify` structural only ([design claim rule](../designs/issue-779-evidencehost-trust-boundary.md#L97-L109)).
