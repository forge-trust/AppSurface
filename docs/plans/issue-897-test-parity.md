# Issue 897 Python-to-C# test parity audit

This is a source-level retirement audit for [`scripts/tests/test_coverage_fanin.py`](../../scripts/tests/test_coverage_fanin.py). It maps all 41 Python `test_*` methods to the current schema-v2 regressions in the [Coverage CLI test project](../../Cli/ForgeTrust.AppSurface.Cli.Tests/) and the related Aspire evidence tests. “Direct” means the inspected C# body asserts the behavior named by the Python test; “Partial” means it asserts a neighboring contract but leaves a specific assertion uncovered; “Changed” means v2 intentionally has a different contract. This audit did not run tests or builds.

`CoverageFanInNativeWorkflowTests.Public_collect_and_capture_runs_primary_and_native_reports_through_strict_normalization` is a real collection fixture for the current host. `CoverageFanInParityTests.PortableThreePlatformCapturesImportComposeAcceptAndVerifyAgainstExactCurrentPolicy` uses portable synthetic captures for Linux, Windows, and Darwin. Neither source body establishes that native tests passed on any runner, much less all three. The historical `EvidenceCoverageFanInTests` suite targets the v1 verifier; its results do not establish v2 parity. `EvidenceCoverageFanInProducerTests` covers the v2 Aspire producer boundary, not shell-wrapper report publication.

## V2 contract differences

The inventory and output changes above are intentional migration differences, not missing v2 parity: the reusable API consumes explicit project identities; output defaults to `Fresh`; an existing generation is reusable only through explicit `ReplaceOwned`; and composition accepts a caller-selected fresh output directory. The v2 API and request behavior are described in the [coverage fan-in guide](../../guides/coverage-fan-in.md) and [Coverage package reference](../../Coverage/ForgeTrust.AppSurface.Coverage/README.md). AppSurface-specific suffix discovery remains in the dogfood adapter. Downstream consumer onboarding/adoption is deferred by the user and is outside this self-contained #897 dogfood gate.

## Remaining evidence and retirement gate

Keep the Python suite until the remaining v2 regression gaps above have an explicit test or retirement decision, the canonical native shell-wrapper report publication path is resolved, and the complete native-evidence proof has actually produced successful Linux, Windows, and macOS evidence. The workflow configuration and portable three-platform fixture are not execution evidence. Do not describe the installed-package proof as downstream adoption proof.

Neither observation is an all-OS native proof. No tests or builds were run while updating this audit.
