# Repository script inventory

This inventory is a source audit of AppSurface at commit [`3f3126a5febff2cb94847bf8a1092b5d61657a18`](https://github.com/forge-trust/AppSurface/tree/3f3126a5febff2cb94847bf8a1092b5d61657a18). It distinguishes executable source from callers, fixtures, and generated assets. A file's shebang or executable bit describes its intended invocation, not proof that it runs on every operating system. Platform evidence is recorded as **unverified** unless the source or its owning workflow establishes otherwise.

The counts describe the checkout immediately before the PWA pilot. New files in the pilot are documented in the [tooling guide](repository-tooling.md).

## Audit method and totals

The tracked-file baseline was `git ls-files --stage -z`, including mode bits. Source counts below are distinct tracked files, while workflow counts are individual `run:` blocks, including multiline blocks. Workflow locators use the workflow path and source line containing the `run:` key. Each block is one independently reviewable inline program or command call site. A workflow line can move, so re-run the audit at the next source revision before using these counts as a baseline.

## Audit limits

This is a source and locator inventory, not a successful-run claim. The baseline establishes tracked paths, executable modes, shebang/source extension classes, and workflow block locations. It does not execute all 209 workflow programs, establish the host prerequisites for every example, or prove Windows/Linux/macOS parity for each script. Treat platform support as unknown until its owning native CI or documented execution evidence says otherwise. At another revision, regenerate the tracked-file and workflow locator lists before relying on historical counts.
